## PART 3 — THE POST ENGINE (how to turn a thread into a post in 7 minutes)

### The 5-Step Engine

```
1. PICK A THREAD          (T1–T12, takes 5 seconds)
2. PICK A FRAME            (one specific moment, hour, sentence, object)
3. PICK A VOICE            (V1 Samir / V5 Krishna / V6 Shiva / V7 Modern Guru)
4. PICK A FORMAT           (LI long / IG carousel / IG reel / 1-liner)
5. RUN THE 3 TESTS         (Geeta's North Star + 3-Second + Mother test)
```

### Frame Examples (the "what to point the camera at")

- **An object:** the notebook, the laptop, the OpenAI bill, the empty cup, the printed user email
- **A timestamp:** 2:14 AM, 11:47 PM, 6:04 AM, Sunday 3 PM
- **A sentence someone said:** the cofounder, the user, the mother, the investor, the trolling commenter
- **A line of code:** one commit, one PR, one deletion
- **A failure:** something broke, something didn't work, something I was wrong about
- **A small win:** one user, one line, one feature finally shipped
- **A practice moment:** sat for 20 min, what arrived, what didn't

### The Voice Mix (per the Geeta)

- **70%** = V1 Samir (you, direct, second-person to the reader)
- **20%** = Voices of users (Arjun/Priya/Diya as composite "M, day 41…" stories)
- **10%** = Voices of gurus (Krishna/Shiva/Modern Guru speaking through the build)

### Format Distribution (locked per Geeta D5)

- **LinkedIn:** 1/day, long-form, signed `— Vatsal`
- **Instagram:** 1/day rotating: carousel / voice reel / quote tile / cinematic
- **No Twitter, no YouTube** (per user decision: IG + LI only for 300 days)
