# LinkedIn 600 — Founder's Voice Bank (v2, mixed lengths)

600 LinkedIn posts. Every post is tagged `[S]` short, `[M]` medium, or `[L]` long, intentionally mixed inside each pillar so the feed never feels monotonous.

| Tag | Words | Use case |
|---|---|---|
| `[S]` short | 25–55 | Hook, one-liner, scroll-stopper |
| `[M]` medium | 80–140 | One teach + mechanism + test |
| `[L]` long | 220–330 | Story + framework + neuroscience + close |

## Format

Each post:

```
P001. [S] <post text>
*<one-line kicker>*

---
```

Posts inside a file are intentionally shuffled — short / long / medium / short / medium / long — so each pillar reads with rhythm, not as a wall of identical blocks.
