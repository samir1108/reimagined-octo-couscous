# THE STUDIO — GAMES CATALOG (36 Flagship Games)
**Pillar 1 of the Studio. Pre-produced, loop-tagged, signal-emitting.**
Status: Catalog locked. Production order at the bottom.

---

## DESIGN LAWS (every game obeys)
1. **One game = one inner faculty.** No multi-purpose games.
2. **Signal out, every session.** Each play writes `studio_game_sessions { signals: jsonb }` the engine can read.
3. **Loop-tagged.** Mandatory `loops_tags[]` linking to Loop Library IDs.
4. **No leaderboards, no XP, no streaks.** Only mirrors.
5. **≤ 7 minutes max.** Most under 3.
6. **Works offline-first.** No AI calls inside the game loop (AI only in pre/post commentary).
7. **One art style across all 36** — Look D (Spirited Away × Soul × Pixar). Locked in MANIFEST.
8. **One sound bible** — pulled from Music Pillar's `beds/` + 24 shared SFX.

## PRODUCTION SPEC (per game, ships in one chat)
```
content/studio/games/G##-slug/
├── design.md          ← mechanic + win + signal schema + loop tags
├── art/               ← Look D keyframes/sprites
├── sfx/               ← references shared SFX library
├── voice-intro.mp3    ← 15s Modern Guru narration
├── component.tsx      ← React/Canvas implementation
└── adapter.ts         ← writes studio_game_sessions row
```

## TECH SPLIT (so we don't over-engineer)
- **React + Framer Motion** (24 games): G01, G03, G04, G05, G08, G11, G14–G15, G19–G36 — fast to build
- **Canvas/WebGL** (8 games): G02, G06, G07, G10, G13, G16, G17, G26 — needs particles/physics
- **MediaPipe webcam** (3 games): G09, G12, G13 — eye/motion detection in browser
- **Mic input** (2 games): G12, G18 — Web Audio API

## SHARED INFRASTRUCTURE (built ONCE, reused 36×)
- `<GameShell />` — pause/exit/voice-intro/results screen
- `useGameSignals()` — emits to `studio_game_sessions`
- `gameRegistry.ts` — id → loader, used by `/studio/games/[id]`
- 24 SFX pack — pulled from Music Pillar
- Look D sprite-sheet — characters, particles, frames
- `<ResultMirror />` — post-game AI commentary (Groq, optional)
