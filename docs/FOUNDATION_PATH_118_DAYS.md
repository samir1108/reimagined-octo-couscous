One foundation. Multiple learning paths. Personalized depth. Continuous adaptation.

## 2. How a day runs

Seven components. The engine chooses which to include and for how long.

| Component | Default | Evidence produced |
|---|---:|---|
| Daily Wisdom | 2–4 min | concept read (participation) |
| Guided Experience | 3–20 min | session completed (participation) |
| Observation | 1–10 min | observation note (self-report) |
| Self-Inquiry | 2–10 min | inquiry answer (self-report) |
| Real-Life Mission | outside app | mission marked done (self-report) |
| Night Reflection | 3–5 min | reflection text + mood (self-report) |
| Integration | 1–2 min | dimension delta + next-day plan (demonstrated) |

Session lengths adapt to available time: **3 / 10 / 20 / 40 minutes**. A 3-minute day
keeps Daily Wisdom + one Guided Experience + Night Reflection. Nothing is "failed" by
choosing the short form.

### Depth by V-Level (same day, different depth)

| V band | Depth | What changes |
|---|---|---|
| 0–1 | 0 Name it | Plain language, one instruction, no philosophy |
| 2 | 1 Describe it | Transitions, two instructions, one checkpoint |
| 3–4 | 2 Observe the observer | Inquiry prompt, mission, less scaffolding |
| 5–6 | 3 Inquire into it | Texts, contradictions, Neti-Neti, longer silence |
| 7+ | 3 | Same content, minimal scaffolding |

Example — **Day 32, Repetitive Thoughts**

| User | Experience |
|---|---|
| V0 | 3-min explanation of a recurring thought. 5-min observation. Name one thought that repeated. |
| V2 | Cognitive lesson on why thoughts repeat. 10-min observation. Identify the trigger of one loop. |
| V3 | Observe the relationship between the thought and the sense of "mine". 15 min. |
| V5 | Investigate whether the thinker is separate from the thought. 20 min + night inquiry. |

Example — **Day 50, Witnessing Emotion**

| User | Experience |
|---|---|
| V0 | Name what is felt. Three check-ins. |
| V2 | Watch an emotion begin, peak, and end. |
| V3 | Witness without identifying with the emotion. |
| V5 | Investigate the distinction between awareness and experience. |

### The four adaptive paths (recommendation layer only)

| Path | Drawn from | Changes |
|---|---|---|
| Observer | dhyana, raja | attention examples, longer sits, fewer words |
| Inquirer | jnana | more inquiry, texts, contradictions |
| Integrator | karma | more missions, repair, behaviour experiments |
| Devotional | bhakti | remembrance, gratitude, surrender |

Raja, Jnana, Bhakti and Karma remain four independent traditions. The four adaptive paths
never rename them.

### Exploration layer (optional, never blocking)

Offered only when the day's required outcome is already met: V-Level explorations,
Neti-Neti, guru teaching, civilization simulation, Bhagavad Gita, Upanishads, Buddhist
psychology, Raja/Jnana/Bhakti/Karma labs.

## 3. The 118 days

Each row is a day: what is taught, what is practiced in-app, what is lived outside it, and
what is asked at night. The engine may swap the practice and the mission by path and depth;
the theme and outcome never change.

## 4. The Day-118 report

Generated from stored evidence, not from the model's opinion. Three classes are reported
separately and never blended into a single "score".

| Section | Source | Class |
|---|---|---|
| Starting profile vs current profile | placement + V-Level history | measured |
| V-Level development history | `v_level` snapshots per session | measured |
| Attention development indicators | observation completion + witness quality | measured |
| Observation practice history | observation notes per chapter | participation |
| Emotional awareness reflections | night reflections, emotion naming | self-report |
| Identified behavioural patterns | loop ledger with severities over time | measured |
| Four Yogic Path affinity | path trials in chapter IX | self-report |
| Most effective practices | completion + re-runs + mood delta | measured |
| Completed wisdom explorations | reading/exploration records | participation |
| Remaining learning gaps | chapters below evidence threshold | measured |
| Recommended next 90-day journey | rules, not AI, then AI prose around the rules | recommendation |

The report must say plainly which numbers are measured, which are self-reported, and which
are inferred.

## 5. The twelve curriculum rules, as executable guards

| # | Rule | Guard |
|---:|---|---|
| 1 | Never advance solely because a session was completed | `advanceIf(evidence >= chapterThreshold)` |
| 2 | Revisit concepts the user struggles with | `reserveConcept()` on failed/abandoned session |
| 3 | Never force advanced inquiry prematurely | `checkBypassingRisk` gate before days 63–67, 81–82 |
| 4 | Contextualize with the user's life domains | `pathAffinity` + `needEngine` examples |
| 5 | Adapt to time and energy | `minutesAvailable` + `energy` input |
| 6 | Introduce the four paths progressively | chapter IX only, previews from chapter VIII |
| 7 | Use guru wisdom when relevant | exploration layer, never the core |
| 8 | Offer civilization simulations as optional | exploration layer, non-blocking |
| 9 | Use Neti-Neti only when ready | depth ≥ 2 and no bypass flag |
| 10 | Never equate a high V-Level with superiority | copy review + no comparative UI |
| 11 | Allow revisiting previous chapters | chapter revisit entry in the Path map |
| 12 | Preserve foundational outcomes when sequence changes | outcome checklist per chapter |

## 6. What the engine returns for any day

```ts
getFoundationDay({
  day: 32,
  vLevel: { band: 3, value: 3.4, microLevel: "entering" },
  adaptivePath: "inquirer",
  pathAffinity: { jnana: 0.7, karma: 0.2, bhakti: 0.1, kriya: 0, tantra: 0, dhyana: 0 },
  minutesAvailable: 10,
  energy: "medium",
})
```

Returns a plan with: theme `Repetitive Thoughts`, depth `2`, components
`[wisdom 2m, guided 5m, observation 2m, night 1m]`, exploration `none`, evidence targets
`["thought-loop-named", "trigger-identified"]`, and a ready `SessionPlan` for
`session-shell`.

The same call at `band: 0` returns depth `0` with `[wisdom 2m, guided 4m, night 1m]` and no
inquiry. Same outcome. Different experience.
