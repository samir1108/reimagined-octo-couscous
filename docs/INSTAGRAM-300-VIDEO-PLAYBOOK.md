# ConsciousOS Instagram Video Playbook — 300 Scripts
## Disney/Pixar Storytelling • 45-60 Seconds • 8-10 Scenes Each

---

## 🎬 HOW TO USE THIS PLAYBOOK

**Format:** Each video = 8-10 scenes. Each scene = ~6 seconds (for Grok AI video generation).
**Style:** Disney/Pixar-inspired character animation. Warm, emotional, cinematic.
**Character:** "Ayu" — a glowing, warm-toned humanoid soul (gender-neutral). Represents every viewer.
**Recurring Elements:**
- 🌀 The Loop — a dark spiral that wraps around Ayu (represents unconscious patterns)
- 💡 The Spark — a warm golden light inside Ayu's chest (represents awareness)
- 🪞 The Mirror — a cosmic mirror that shows Ayu's true self
- 🌅 The Sunrise — represents awakening, new beginning
- 📱 The Companion — a small glowing orb that floats beside Ayu (represents ConsciousOS)

**Music Direction:** Ambient piano + soft strings. Build to emotional crescendo in scenes 7-8. Resolve in warmth.

**CTA Pattern:** Scene 9-10 always ends with ConsciousOS branding + "The journey inward begins" or variant.

- **Joyful (Series 20, 27, 30):** Light piano + acoustic guitar. Warmth.

- Every caption should read like a complete micro-post
