User reaches consciousness milestone → Earns visual badge →
Badge designed for social sharing → Posted to Instagram/LinkedIn →
Followers curious → Download app → ...

Viral coefficient target: 0.15

Loop 3: The Community Loop
User posts observation → Other users resonate/react →
Discussion creates value → Lurkers see value → Join community →
Post their own observations → ...

Engagement rate target: 15% DAU/MAU

Loop 4: The Teacher Loop
Teacher uses platform → Recommends to students →
Students use app → Students improve → Students recommend teacher →
Teacher recommends to more students → ...

k-factor target: 3-5 students per teacher per month

Loop 5: The Enterprise Loop
Employee uses app → Improves wellbeing → Manager notices →
Manager recommends to team → Team adopts → HR notices →
Company buys enterprise license → Deploys to all employees → ...

Enterprise conversion from bottom-up: 5% of companies with >20 employees
