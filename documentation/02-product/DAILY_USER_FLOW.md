## Phase 1: Morning Session (5:00 AM - 12:00 PM)

### 1.1 Entry Points

| Entry Method | Trigger | Experience |
|--------------|---------|------------|
| **Scheduled Ping** | 5:00 AM - 6:00 AM | Gentle notification "Good morning, your day awaits" |
| **Dream Journal** | 5:00 AM - 9:00 AM | "Did you dream last night?" prompt |
| **User Opens App** | Any time before 12 PM | Direct to Morning Session |
| **Voice Command** | "Start my day" | Hands-free initiation |

### 1.3 Morning Block Types

| Block Type | Description | Duration | XP Reward |
|------------|-------------|----------|-----------|
| **Practice** | Guided meditation, breathwork, pranayama | 5-20 min | +20-35 XP |
| **Learn** | Wisdom content, teaching, technique explanation | 5-15 min | +20-30 XP |
| **Reflect** | Journal prompt, self-inquiry, pattern recognition | 5-10 min | +15-25 XP |
| **Inquiry** | Deep questioning, witness exploration | 10-20 min | +25-35 XP |
| **Embodiment** | Body awareness, movement, somatic practice | 5-15 min | +20-30 XP |
| **Shadow Work** | Pattern exploration, integration work | 15-30 min | +30-45 XP |

|------------|---------|--------|--------|
| **Morning** | Session + 1-2 blocks | 35 XP | 85 XP |
| **Midday** | Presence | 15 XP | 25 XP |
| **Day** | 2-4 additional blocks | 40 XP | 140 XP |
| **Evening** | Session | 20 XP | 20 XP |
| **Night** | Dream Journal | 10 XP | 10 XP |
