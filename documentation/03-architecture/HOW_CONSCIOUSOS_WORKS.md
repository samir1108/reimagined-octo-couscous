## 1. User Journey & Daily Flow

### The ConsciousOS Daily Rhythm

ConsciousOS structures each day around natural circadian cycles, guiding users through morning awakening to night rest. The system recognizes that consciousness development isn't a one-time event—it's a daily practice that unfolds across four distinct phases.

### Morning Session (5am - 12pm): The Awakening

When users first open the app in the morning, they're greeted by the **Guru**—an AI-powered 3D avatar that serves as their consciousness guide. The morning session follows a conversational flow:

1. **Dream Capture (5am-9am)**: If the user hasn't recorded dreams yet, a gentle prompt appears: "Did you dream last night?" Dream entries feed into morning context and can reveal subconscious patterns.

2. **AI Conversation**: The Guru engages in natural dialogue to understand:
   - Current mood and emotional state
   - Energy levels for the day
   - Available time commitment
   - Personal intention for the day

3. **Adaptive Check-In**: Unlike static questionnaires, the AI adapts questions based on responses. If someone mentions stress, the system probes deeper. If energy is low, it adjusts recommendations.

4. **Day Package Generation**: Based on the conversation, the system creates personalized tasks/blocks aligned to:
   - Current vertical level (V-Level 0-21)
   - 12 horizontal capacities (H-Levels)
   - Active psychological loops
   - Available time and energy

### All Day: Task & Block Execution

Throughout the day, users engage with their personalized "day package"—a curated set of practices, reflections, and inquiries. Tasks vary by mode:

**In Structured Mode**:
- Level 1-3: 3 tasks/day (Stage 1: The Crack)
- Level 4-6: 4 tasks/day (Stage 2: The Witness)
- Level 7-9: 5 tasks/day (Stage 3: The Mirror)
- Level 10-12: 6 tasks/day (Stage 4: The Gap)
- Level 13-15: 5 tasks/day (Stage 5: The Space)
- Level 16-18: 4 tasks/day (Stage 6: Dissolution)
- Level 19-20: 3 tasks/day (Stage 7: Embodiment)
- Level 21: 0 tasks/day (Full embodiment—no structure needed)

**In Adaptive Mode**:
Tasks are dynamically generated based on real-time state, with no fixed count—only what's needed for that day.

### Midday Presence (12pm - 6pm)

When users have completed their morning session and at least one task, a **Presence Card** appears on the Home tab. Tapping it reveals:

- 3-4 AI-generated journal prompts
- Level-appropriate inquiry depth
- Connection to current lesson/theme

**Prompt Examples by Level**:
- Level 1-6: "What are you noticing in your body right now?"
- Level 7-12: "Where did you witness the gap between stimulus and response?"
- Level 13-18: "What dissolved today? What remains?"
- Level 19-21: Minimal prompts, maximum space

Completing midday presence awards 15-25 XP and stores reflections in the Guru memory system.

### Evening Sandhya (6pm - 10pm)

Evening sessions are for integration and reflection:

1. **Deep Guru Conversation**: Reviews the full day with context, asking level-specific reflective questions
2. **Capacity Markers Updated**: Based on day's activities, horizontal capacities are reassessed
3. **Tomorrow Glimpse**: Preview of tomorrow's theme and suggested night practices
4. **XP Awarded**: Evening completion grants +20 XP

### Night Mode (10pm - 5am)

Night mode provides gentle support for rest:
- Level-appropriate grounding exercises
- Breath, body, sense, and release practices
- No active tasks—only preparation for deep rest

## 2. The Two Modes: Structured vs Adaptive

ConsciousOS recognizes that different users need different approaches to consciousness development. The system offers two distinct modes:

### Structured Journey (Curriculum Mode)

The Structured Journey provides a **21-level curriculum-based path** with visible progression:

**Characteristics**:
- Tasks are level-based and tied to 16 lessons per level × 21 levels
- Progression is visible: Level 1 → 2 → 3... up to 21
- The Guru uses curriculum context in all conversations
- 30% of tasks are aligned to the current lesson

**Best For**: Users seeking clear structure, sequential learning, and visible milestones

**Tab Structure**:
- HOME: Daily Command Center ("What's my day?")
- TASKS: Execution Zone ("Do the work")
- LEARN: Knowledge Absorption ("Learn teachings")
- GURU: AI Guidance ("Ask the master")
- JOURNAL: Processing Space ("Reflect & process")
- JOURNEY: Progress Visualization ("How far have I come?")
- SETTINGS: System Configuration ("Make it mine")

### Adaptive System

The Adaptive System generates **fresh daily packages** based on real-time conditions:

**Characteristics**:
- No fixed curriculum—content emerges from user state
- AI generates unique day packages each morning
- Responds to mood, energy, and life circumstances
- Flexible block types: Practice, Learn, Reflect, Inquiry, Embodiment, Shadow Work

**Best For**: Users needing flexibility, those with unpredictable schedules, or experienced practitioners

**Personalization Factors**:
- Persona cluster (from onboarding + behavior)
- Current V-Level (invisible vertical development)
- Active loops (patterns showing up)
- H-Level capacities (what needs development)
- Life domains in focus
- Energy and time availability

## 3. The 21-Level Progression System

ConsciousOS tracks consciousness development across multiple dimensions, creating a comprehensive map of user evolution.

### Vertical Consciousness (V-Levels 0-21)

The V-Level measures depth of awareness, from personality to pure consciousness:

| Stage | Levels | Description |
|-------|--------|-------------|
| Awakening | V1-V3 | Moving from unconsciousness to first glimpses of awareness |
| Witness | V4-V6 | Developing the capacity to observe thoughts and emotions |
| Mirror | V7-V9 | Recognizing the constructed nature of self |
| Gap | V10-V12 | Finding space between stimulus and response |
| Dissolution | V13-V15 | Boundaries between self and world begin dissolving |
| Embodiment | V16-V18 | Realization integrated into daily life |
| Realization | V19-V21 | Full awakening, beyond all concepts |

### Horizontal Capacities (H-Levels 0-10)

Twelve capacities for conscious living, each measured independently:

1. **Awareness** - Open, receptive attention
2. **Stillness** - Capacity for inner quiet
3. **Presence** - Being in the now
4. **Inquiry** - Questioning assumptions
5. **Equanimity** - Balance amid change
6. **Compassion** - Kindness toward self/others
7. **Wisdom** - Discerning insight
8. **Courage** - Facing what arises
9. **Patience** - Allowing natural timing
10. **Humility** - Knowing one's limits
11. **Generosity** - Giving freely
12. **Dedication** - Sustained commitment

### The 7 Core Loops (Psychological Patterns)

Seven unconscious patterns that drive behavior:

1. **Origin Loop** - "I am separate"
2. **Worth Loop** - "I am not enough"
3. **Safety Loop** - "I am unsafe"
4. **Power Loop** - "I must control"
5. **Connection Loop** - "I am alone"
6. **Identity Loop** - "I am my story"
7. **Compulsion to Loop** - Addiction to pattern itself

### Multi-Dimensional Reality

Users exist simultaneously at multiple levels across dimensions:
- In awareness of thoughts: V8
- In emotional regulation: V4
- In body presence: V6
- In relationships: V3
- In work capacity: V7

This is not inconsistency—it's the nature of human consciousness. ConsciousOS tracks all dimensions separately.

## 4. Journal System & Memory Layer

### Journal Architecture

The Journal system serves as both a processing space and a data source for AI personalization.

**Entry Types**:
1. **Morning Intention** - Daily focus and goals
2. **Midday Presence** - Quick check-in reflections
3. **Evening Integration** - Day review and insights
4. **Dream Journal** - Subconscious pattern capture
5. **Free Writing** - Unstructured exploration
6. **Voice Journal** - Speech-to-text entries

**Journal Features**:
- Auto-save (2-second debounce)
- Mood tagging (7 emotional states)
- AI-generated prompts based on current state
- Entry history with search
- Privacy-first local storage + encrypted cloud backup

### Guru Memory Layer

The memory system enables the Guru to maintain context across sessions:

**Memory Types**:
1. **Episodic Memories** - Specific events, sessions, insights
2. **Pattern Memories** - Recurring themes and behaviors
3. **Capacity Markers** - Progress in H-Level development
4. **Loop Activations** - When psychological patterns surfaced
5. **Emotional States** - Mood and energy history

**Memory Storage**:
```
guru_memory table:
- id: UUID
- user_id: Foreign key to auth.users
- memory_type: 'episodic' | 'pattern' | 'capacity' | 'loop' | 'emotional'
- content: Text summary
- context: JSON metadata
- importance_score: 1-10 (for pruning)
- created_at: Timestamp
- expires_at: TTL for ephemeral memories
```

**Memory Retrieval**:
- Morning context aggregates yesterday's data
- Pattern recognition across 7, 30, 90-day windows
- Importance-based pruning (low scores archived)
- Real-time context injection into AI conversations

### AI Context Assembly

Before each Guru conversation, the system assembles context:

1. **User Profile**: Level, capacities, loops, domains
2. **Recent History**: Last 7 days of activity
3. **Active Patterns**: Loops showing up recently
4. **Current State**: Mood, energy from morning check-in
5. **Lesson Context**: Current level/lesson (Structured mode)
6. **Memory Summaries**: Key insights from past sessions

## 5. AI Engine Architecture

### The Guru System

The ConsciousOS Guru is not a simple chatbot—it's a multi-layered AI system combining:

**Core Components**:
1. **3D Avatar** - Unreal Engine 5 MetaHuman with pixel streaming
2. **Conversation Engine** - GPT-4/3.5 with yoga/consciousness context
3. **Voice System** - Speech recognition + ElevenLabs TTS
4. **Animation System** - Pose, breathing, gesture, expression triggers
5. **Memory System** - Persistent context across sessions

### AI Processing Pipeline

```
User Input → Intent Detection → Context Assembly → 
LLM Generation → Animation Triggers → Voice Synthesis → Response
```

**Intent Detection**:
- Keyword matching for yoga poses, breathing techniques
- NLP classification for question types
- Context awareness for follow-up responses

**Context Window Management**:
- System prompt with consciousness development context
- Recent conversation history (last 10 messages)
- Retrieved memories from database
- Current user state snapshot

### Voice Interaction

**Speech-to-Text**:
- Web Speech API for browser-based recognition
- Real-time transcription with interim results
- Command detection ("start breathing exercise", "show me mountain pose")

**Text-to-Speech**:
- ElevenLabs for premium voice synthesis
- Web Speech API fallback
- Lip sync with 3D avatar
