## 1. User Journey: The Daily Flow

### Morning Awakening (5am - 12pm)

When users open ConsciousOS in the morning, they enter a **guided awakening process** designed to set the tone for conscious living:

**Dream Capture (5am-9am)**: Before full waking consciousness takes over, the app gently asks, "Did you dream last night?" Dreams are stored in the Guru memory system and analyzed for recurring patterns, emotional themes, and subconscious processing.

**The Guru Conversation**: Users don't fill out forms—they have a natural dialogue with an AI-powered 3D avatar. The Guru asks about:
- Current mood and emotional weather
- Energy levels (physical, mental, emotional)
- Available time for practice today
- Personal intention or focus for the day

The AI adapts dynamically. If a user mentions anxiety, the Guru probes deeper: "Where do you feel that in your body?" If energy is low, it suggests gentler practices. This isn't a survey—it's the beginning of a relationship.

**Day Package Generation**: Based on this conversation, the system generates a personalized set of tasks called a "day package." In Structured Mode, this means 2-6 tasks aligned to the user's current level. In Adaptive Mode, it means AI-generated blocks matched to real-time state.

### All Day: Task Execution (Chained Tasks)

Users work through their day package at their own pace. Each completed task:
- Awards 20-35 XP
- Updates capacity markers
- Feeds data back to the Guru memory system
- Unlocks the next task in the chain

Tasks aren't random—they're matched to the user's current development across 12 horizontal capacities (awareness, stillness, presence, inquiry, etc.) and 9 life domains (work, relationships, health, etc.).

### Midday Presence (12pm - 6pm)

When morning is complete and at least one task is done, a **Presence Card** appears. This is a gentle check-in—not a demand, but an invitation. Tapping it reveals 3-4 AI-generated journal prompts tailored to the user's current level.

**Level-Appropriate Prompts**:
- Level 1-3: "What are three things you can see right now?"
- Level 7-9: "Where did you contract today? Where did you expand?"
- Level 13-15: "What dissolved? What remains?"
- Level 19-21: (Just space—a blank page)

Midday presence awards 15-25 XP and creates episodic memories for the Guru.

### Evening Sandhya (6pm - 10pm)

Evening sessions are for **integration and reflection**. The Guru reviews the day with context:
- "I see you completed three tasks—how did that feel?"
- "You mentioned anxiety this morning. Did it shift?"
- Level-specific reflective questions

This conversation updates capacity markers, generates insights, and creates a "Tomorrow Glimpse"—a preview of what tomorrow might bring, including suggested night practices.

### Night Mode (10pm - 5am)

Night mode is minimal and grounding. No tasks. Just:
- Gentle grounding exercises
- Breath awareness practices
- Sleep preparation support

The goal is transition from doing to being.
