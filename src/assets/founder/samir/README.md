# Samir — Founder Asset Bible

All photos here belong to the §29 *Live Portrait Founder Format* in `/mnt/documents/ig-content.md`.

## Folder rules

- `portraits/` — eye-to-camera, single-light, painterly-graded. Used for reel cover frames + landing page.
- `in-room/` — wide/mid shots in his actual room (hoodie, books, diya, window). Bio header + press kit.
- `with-product/` — phone in hand showing the app. F-PROD sub-format only.
- `raw/` — unprocessed source files. NEVER published directly. Must pass LUT-01 first.

## Hard rules (locked)

1. Founder face appears in **at most 1 in 5 reels**. Scarcity is the moat.
2. Founder photo never sits next to a guru portrait in the same frame.
3. Founder photo never on a generic quote tile.
4. Every published image must pass §27.5 mute test.

## Naming

`samir-{folder}-{slug}-{NN}.{jpg|png}` — e.g. `samir-portraits-hoodie-01.jpg`.
