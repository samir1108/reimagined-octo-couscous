## 60. QUESTIONNAIRE SYSTEM (7 Assessments → AI-Generated Programs)

### The Flow:
1. User takes questionnaire (5-10 min, 20-50 questions)
2. AI analyzes results and shows personalized type
3. User taps "Generate My Personal 30-Day Program"
4. AI generates unique 30-day program based on their pattern
5. User follows the program with daily practices and live guru chat
6. After 30 days, reassessment → next program recommended

### 7 Questionnaires Built:

| # | Questionnaire | Questions | Time | Results |
|---|--------------|-----------|------|---------|
| 1 | Energy Body Assessment | 50 | 10 min | Thinker, Feeler, Instinctive, Balanced, Blocked |
| 2 | Sleep & Dream Mapping | 20 | 5 min | Restless, Heavy, Dreamer, Peaceful |
| 3 | Relationship Pattern Map | 25 | 6 min | Anxious, Avoidant, Secure, Fearful-Avoidant |
| 4 | Money & Abundance Energy | 20 | 5 min | Abundant, Scarcity, Unworthy, Spiritual Avoider |
| 5 | Purpose & Direction Finder | 25 | 6 min | Aligned, Lost, Trapped, Numb Drifter |
| 6 | Inner Child State | 20 | 5 min | Nurtured, Abandoned, Criticized, Parentified |
| 7 | Creative Flow State | 20 | 5 min | Flowing, Blocked, Scattered, Fearful |

### Each Questionnaire Has:
- **Questions in English + Hinglish** (every question has Hindi translation)
- **4 options per question** with scoring for each result type
- **Tag-based input** (quick tap options) + free text
- **Beautiful UI** with progress bar, smooth transitions
- **Results page** with icon, description, recommended guides, recommended practices
- **"Generate My 30-Day Program" button** — calls AI edge function

### AI Program Generation (Edge Function):
`supabase/functions/generate-personal-program/index.ts`

**How it works:**
1. Takes questionnaire result + guide recommendations + scores
2. Sends to GPT-4o-mini with guide's personality prompt
3. AI generates 30-day program:
   - Days 1-7: Awareness (notice the pattern)
   - Days 8-14: Understanding (why it exists)
   - Days 15-21: Experimentation (try new responses)
   - Days 22-30: Integration (make it natural)
4. Every 5th day is "gentle day" — lighter practice
5. Each day has: title, teaching, practice, duration, chat prompt
6. Saves to `personalized_programs` table in Supabase

### Database Table:
`personalized_programs` — stores AI-generated programs with user_id, questionnaire_id, result_id, guide_id, program_data (JSONB), current_day, started_at, etc.

### Post-30-Day Assessment:
After completing a 30-day program, user answers 4 follow-up questions:
1. "Compared to 30 days ago, how do you feel?"
2. "What was the most impactful practice?"
3. "What still feels unresolved?"
4. "Ready for deeper work or need more time?"

AI then generates "next steps" — either a deeper program, continuation, gentler approach, or different path.

## 61. CORE PRACTICE: THE WITNESS (Sakshi Bhav)

### The Flagship Practice of the Entire App

**What It Is:**
Open-eye meditation where user observes their 3 brains (Head, Heart, Gut) without getting caught in thoughts. This is the #1 core practice — above everything else.

**The Flow:**
1. User taps "The Witness" button in Temple Hall
2. Chooses duration (5/10/20/30 min)
3. Timer starts with soft bell
4. User keeps eyes open, soft gaze
5. Every 5 minutes: gentle bell + reminder "Are you watching... or caught?"
6. **Live Guru Chat** — user can type what they feel (Hinglish ok), guru responds live
7. After timer: 5-step reflection (emotions, body, thoughts, 3 brains detail, overall)
8. AI generates post-session report based on practice data

### Live Guru Chat During Practice:
`src/components/temple/WitnessChat.tsx`

**How it works:**
- Collapsible chat panel at bottom of practice screen
- User types: "chest mein tightness hai" or "aisa thoughts aa rhe hai"
- AI responds in guide's voice (1-2 sentences, like guru sitting beside them)
- Hinglish supported — AI responds in same language user uses
- Context-aware — guide knows user is in Witness practice, so guidance is about OBSERVING, not fixing
- Example:
  ```
  User: "mujhe dard ho rha hai"
  Aarav: "Good. Don't try to release it. Notice WHERE it lives.
          Sharp or dull? Moving or still? The witness doesn't fix. It sees."
  ```

### Post-Session AI Report (Edge Function):
`supabase/functions/practice-report/index.ts`

After each practice session, AI generates a personalized report:
1. Observation about today's practice
2. Specific moment or pattern noticed
3. Gentle guidance for next time
4. Short teaching or insight
5. Written in guide's characteristic voice
